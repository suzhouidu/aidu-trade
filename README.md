# 爱度科技 · 跨境外贸服务官网

外贸独立站、CRM / ERP、代运营——帮国内中小外贸企业把“站 + 系统 + 获客”一次配齐，按月收服务费。

- 技术栈：Next.js 15（App Router）+ React 19，部署在 Vercel
- 域名：trade.7887.cn（DNS 由域名处加 CNAME 指向 Vercel 部署域名后生效）
- 留资表单：`/api/lead` 接收提交并记录，成功后显示确认信息（邮件通知后续再接）

## 本地开发

```bash
npm install
npm run dev
```

## 部署

推送到 GitHub `main` 分支后，Vercel 自动部署。

## 承诺口径

本站只承诺交付物、周期与验收标准，不承诺询盘量、排名、成交额、涨粉数。价格均为“起”，具体以书面报价为准。
